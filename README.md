# Skinchanger Simplifier for League 🎮

A Python program that makes installing custom skins for League of Legends easier and faster.

## 📚 About the Project

This tool automates the process of downloading and installing custom skins from skinchanger websites.

Instead of manually downloading files, finding the correct folders and moving everything yourself, the program handles these steps automatically.

## 🚀 Features

- Automatically downloads skin files from supported skinchanger websites.
- Downloads the required `.wad` and `meta` files.
- Places the downloaded files in the correct directories.
- Makes skins ready to select in your skinchanger program.
- Simplifies the entire skin installation process.

## ⚙️ How It Works

1. Find a skin you want to use on a supported website.
2. Use the program to download the skin files.
3. The program automatically places the files in the correct location.
4. Open your skinchanger program.
5. Select your downloaded skin and enjoy!

## 🛠️ Technologies

- Python

## 🎯 Goal

The goal of this project is to save time and make installing custom League of Legends skins easier by automating repetitive tasks.
